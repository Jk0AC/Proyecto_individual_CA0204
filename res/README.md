# Resultados del proyecto

Esta carpeta contiene el **informe final en formato PDF**, generado mediante el 
renderizado del documento principal **Quarto (`.qmd`)**.

## Contenido

El archivo PDF integra la metodología, los análisis estadísticos, las simulaciones 
de Monte Carlo, los resultados de las carteras de inversión y sus respectivas visualizaciones.

## Generación del informe

El documento se genera automáticamente al renderizar el archivo `.qmd`, que ejecuta 
los scripts de R ubicados en la carpeta `cod/` mediante la función `source()`.

Por tanto, **el PDF constituye la salida final del proyecto**, mientras que el 
código fuente y los procedimientos utilizados para su elaboración se encuentran
documentados en los archivos correspondientes.
